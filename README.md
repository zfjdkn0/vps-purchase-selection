## 配置怎么定：512MB 到 12GB，按用途对号入座

先想清楚这台机器跑什么，配置下限就定了。建站至少 1GB 内存起步，跑应用 2GB 起步，纯测试 512MB 也够用。这是几家购买教程里说法最一致的一条。

再往下细分，可以按四档看：

512MB 和 1GB 这一档跑静态博客、轻量代理、开发测试环境。512MB 偏紧，装个面板再跑点东西就开始吃 swap，1GB 是更舒服的起点。2GB 和 4GB 跑 WordPress 这类动态站点、小型数据库、轻量应用后端，建站我建议 2GB 起步，插件一多、缓存一开，1GB 很快就撑不住。6GB 和 8GB 用来跑多个站点、中型数据库，或者稍微吃内存的服务。12GB 以上是资源密集型应用，或者一台机器多用途并行。

新手最容易犯的错是"配置越高越好"，其实不是。有个写 RackNerd 购买教程的作者说过一句很实在的话：跑一个每天几百 PV 的博客，1GB 内存绰绰有余，多花的钱基本是浪费。

反过来，也别为了省几块钱买太小。台湾远振公开的加购价目表能说明问题：加购 CPU 每核每月新台币 210 元，加购内存每 GB 每月也是 210 元，加一个额外 IP 每月 250 元，加 1TB 流量 3000 元。一台低配机器后期加内存的价格，往往比当初直接买高一档的整机还贵。硬盘和流量同理，有存储需求才需要为硬盘加钱，流量则要按你每月实际跑的量估，图片站、视频站吃流量很快，纯文字站一个月几百 GB 都用不完。

第一次买，我建议先上月付的 1GB 或 2GB，跑一个月看监控里的内存和带宽曲线，真有瓶颈再升。升级基本都能升，降级基本都不行，远振的条款里就明写补差价升级可以，升级使用后不能申请降级。

## 机房与线路怎么选：距离决定下限，线路决定上限

一句话原则：机房离目标用户越近越好。受众在中国大陆，选美西的洛杉矶、圣何塞，或者香港、日本、韩国；受众在东南亚和东亚，圣何塞、西雅图这类跨太平洋路由比较稳；受众在北美，纽约、阿什本、芝加哥按具体城市挑最近的；受众在欧洲，阿姆斯特丹、法兰克福、伦敦差别不大。

中国大陆用户还有一个额外变量：线路。搬瓦工的教程里给过一份机房好坏排序，HK > DC6 CN2 GIA-E > DC9 CN2 GIA > DC8 CN2 > DC3 CN2 ≈ DC2 QNET ≈ DC4 MCOM ≈ Fremont。这是那家商家自己的机房分级，但规律通用：香港最好，CN2 GIA 次之，普通 CN2 再下一档，没做优化的国际线路排最后。预算够就上 CN2 GIA，预算紧就走普通优化线路，别指望 50 元一月的机器跑出 CN2 GIA 的延迟。

买完能不能换机房，取决于商家，这点必须在付款前查清楚。RackNerd 的机房在购买时就定死，想换只能新开一台目标机房的机器，把数据迁过去再退掉旧的。搬瓦工反过来，支持购买后迁移机房且流量不变，但香港 PCCW 方案不可迁移。同一个行业，两套政策，下单前问一句能省掉后面很多麻烦。

## VPS购买流程六步：从选套餐到拿到 root 密码

流程各家大同小异，下面这六步照着走基本不会漏：

1. **选套餐进配置页**。按内存和价格挑一款，点 Order Now 或者对应按钮，进入配置页。
2. **选机房位置**。配置页第一个选项通常是数据中心。同一个套餐在不同机房的可选情况不完全一样，特价套餐能选的机房往往更少。这一步定错了，后面要么迁移要么重买。
3. **选操作系统**。Linux 免费，常见选项有 Ubuntu、Debian、CentOS、AlmaLinux、Rocky Linux，新手选 Ubuntu 或 Debian，社区资料最多，遇到报错搜得到答案。Windows 要额外付授权费，而且按核计费。
4. **选计费周期**。月付、季付、半年付、年付，年付单价最低，代价是一旦买了不能退款。第一次用某家商家，先月付试一个月，比直接上年付稳妥。
5. **填账号信息、选支付方式**。注册要填邮箱、密码、账单地址。邮箱一定要填对，多数商家把邮箱当登录名。国内用户最方便的是支付宝，结账页的支付方式里选 Alipay，跳转扫码付款，跟在国内电商下单差不多。六六云的测评页面写明支持支付宝。
6. **等开通邮件**。付款完成后几分钟到十几分钟，会收到开通通知，里面有 IP 地址、root 密码和控制面板地址。有商家的购买教程记录得比较细：5 到 15 分钟内收到两封邮件，一封是订单确认，另一封标题是 KVM VPS Login Information，拿到后面这封就算开通完成。

拿到 IP 和密码就能登录。Windows 用 Bitvise SSH 这类客户端，Mac 和 Linux 直接开终端，输入 `ssh root@你的IP`，粘贴密码时终端不显示任何字符，这是正常现象，回车就行。

注册环节有几个细节容易出错：国家选中国，密码设强一点，用户条款前面那个勾必须勾上，不勾提交不了。有的商家结算页有 Promotional Code 输入框，填完要点 Validate Code 验证，没验证等于没填。

## 买之前必须知道的坑，哪些人不该买

**不退款是行业常态。** RackNerd 的服务条款明写任何产品都不支持退款，也没有无理由退款保证。台湾远振写得更直接：VPS 属于高度可自定义的环境，较无相容性问题，因此不提供退费，需要测速请申请虚拟主机产品试用。六六云的退款条款我没有查到明确说法，下单前自己去官网条款页确认一遍。年付一锤子买卖，先月付试一个月是更稳的做法。

**跑路风险真实存在。** 那位写 RackNerd 教程的作者讲过自己的经历：选过月付两美元的超低端商家，结果没跑三个月就跑路了，钱和站点一起没。价格低到不合常理的商家，先查它成立了几年、有没有公开的公司信息。

**IP 被墙是要花钱的。** 搬瓦工的规则是购买后分配的 IP 被墙，24 小时内联系客服可以更换；使用途中被墙，等 10 周可免费换，或者付费约 8.x 美元换。IP 被墙期间更换机房的功能也不能用。RackNerd 换 IP 同样收费，工单申请，几美元一次。这笔钱买之前不会有人提醒你。

**别人的测速对你没参考意义。** 搬瓦工的教程点名过几个方向：部分广东电信的线路对国外速度限制严重，长城宽带、鹏博士的问题更明显。同一个机房，别人跑得动你未必跑得动，先确认是不是本地宽带的锅。

**禁止项目要看条款。** 远振列出的禁止项包括滥发垃圾邮件、游戏私服和外挂站、黑帽 SEO、公开的 Web Proxy 服务，以及过度消耗资源的 CGI 论坛聊天室。公开代理被禁是很多商家的共同条款，买之前翻一遍 TOS，别等被封了才发现。

**六六云的真实短板。** vps55 在 2026 年 10 月发过一篇美国 AS4837 特价年付机的测评，测试环境是电信线路：延迟 186ms，下载 8.43Mbps，上传 63.10Mbps，三网回程全部走 AS4837 普通线路。IP 质量方面，检测为美国原生 IP，多数数据库识别为家宽，但 IP2Location 判为 IDC 机房 IP，部分 AI 平台不兼容。这个结果说明它够用但不算快，4837 是普通线路，别拿它当优化线路期待。要低延迟就选 CN2 GIA 或 9929 那两档。

**这几类人别买。** HostAdvice 对无管理 VPS 的定义说得很清楚：自己装软件、配 SSL、配备份、配防火墙和 CDN、监控排障全靠自己。你要是需要有人帮你处理这些，需要 7×24 电话支持和明确的 SLA，或者预期会有大流量，廉价 VPS 不是你的选项，去看全管理方案或者虚拟主机。还有一类人是有技术但不想碰命令行，同样别买，省下来的钱不够买折腾的时间。

## 常见问题

### 买了之后能换机房吗？

看商家。RackNerd 不能，机房购买时定死，只能新开一台目标机房的机器迁数据。搬瓦工可以，购买后能迁移机房且流量不变，但香港 PCCW 方案不可迁移。六六云这一条我没有查到明确说明，下单前问客服或者翻条款页。

### 能升级套餐吗？

一般能升不能降。远振明写可以在流量不足时补差价升级，升级使用后不能申请降级。RackNerd 是后台点一下升级，重启一次生效，差价按比例补。想省钱又怕买小，就按月付先跑着。

### 能装 Windows 吗？

能，但要额外付授权费，而且通常按核计费。远振的价格是每核每月新台币 120 元，同时建议 Windows 方案用 2GB 以上内存，1GB 跑重一点的程序容易内存不足直接中断。做 ASP 或者必须用 Windows 软件才考虑，纯建站用 Linux 免费系统更划算。

### 支付宝能付款吗？

六六云的测评页面写明支持支付宝。操作是在结账页的支付方式里选 Alipay，跳转后扫码付款。这套流程在多数面向国内用户的海外商家那里都一样。

### 付款后多久能开通？

几分钟到十几分钟。有商家的购买教程记录是 5 到 15 分钟收到订单确认和登录信息两封邮件。超过半小时还没收到，先翻垃圾邮件箱，再发工单问。
